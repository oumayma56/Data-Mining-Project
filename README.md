# Data-Mining-Project
Data Mining Project: Customer Segmentation
You can find more information about the guidelines of the project in the project organisation folder.
This project is mainly about clustering and classifying the behaviour and preferences of customers in order to  create marketing strategies based on the insights found.
How I approached this project:
- Understanding the meta data and exploring the statistical distriution
- Data preprocessing mainly handling missing data, duplicates and outliers, data scaling
- Selecting the features to include in the data mining model
- Assessing the results of different classification models: Kmeans, Self organizing map
- Choosing the model that provide distinct and clear clusters
- Data profiling to understand the characters of each cluster
